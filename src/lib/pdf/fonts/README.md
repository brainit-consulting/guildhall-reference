# Fonts for invoice PDFs

The two DESIGN.md typefaces as TTF files, because react-pdf can't use `next/font`. Latin subsets from Fontsource
(`cdn.jsdelivr.net/fontsource/fonts/<font>@latest/latin-<weight>-normal.ttf`), fetched 2026-10-12.

- `YoungSerif-Regular.ttf`: Young Serif by Bastien Sozeau, SIL Open Font License 1.1.
- `IBMPlexSans-Regular.ttf`, `IBMPlexSans-Medium.ttf`: IBM Plex Sans by IBM, SIL Open Font License 1.1.
